# 🛍️ Retail Shop Management System

A simple Retail Shop Management System built using **FastAPI, SQLAlchemy, MySQL, HTML, CSS, and JavaScript**.

This project demonstrates how a retail shop can manage products, customers, stock, and orders through REST APIs and a simple web interface.

---

## 📌 Project Overview

The Retail Shop Management System provides basic functionality for managing a retail store.

The system allows the shop owner or staff to:

- Manage products
- Manage product stock
- Manage customers
- Create customer orders
- Add multiple products to a cart
- Automatically calculate order totals
- Reduce product stock when an order is created
- Complete or cancel orders
- Restore stock when an order is cancelled
- View basic information through a dashboard

The project is designed as a **simple demonstration project** to understand backend API development, database connectivity, CRUD operations, and frontend-backend integration.

---

## 🎯 Objectives

- Build a REST API using FastAPI
- Connect FastAPI with MySQL
- Use SQLAlchemy ORM for database operations
- Implement CRUD operations
- Understand database relationships
- Implement business logic using service and repository layers
- Connect a frontend with backend APIs
- Manage orders and stock
- Create a simple retail shop management workflow
